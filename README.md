# Quantum Computing Systematic Review — Supporting Data

Supporting aggregate data and reproduction materials for **From Quantum Possibility to Quantum Utility: A Cross-Domain Systematic Review and Six-Level Evidence Framework**, by Jesus Rafael Gil Lopez and Nasseh Tabrizi.

## Available materials

- [Dataset: annual publication counts by domain](Quantum_Review_GitHub_Ready/data/domain_year_counts.csv)
- [Reconstructed Python reproduction script](Quantum_Review_GitHub_Ready/code/reproduce_domain_trends.py)
- [Figure 2(a) verification report](Quantum_Review_GitHub_Ready/verification/figure2a_verification.csv)
- [Full documentation and reproduction instructions](Quantum_Review_GitHub_Ready/README.md)
- [Data dictionary](Quantum_Review_GitHub_Ready/DATA_DICTIONARY.md)

The dataset summarizes **1,172 Scopus search occurrences** across eight overlapping search domains (QC01–QC08), not 1,172 unique studies.

## Scope of reproducibility

This release supports the aggregate publication trends in **Figure 2(a) only**. It does not release the 778-record deduplicated bibliometric database, the 349-review screened corpus, screening decisions, or the analyses underlying Figures 2(b) and 2(c). The source workbook and licensed Scopus metadata are not redistributed.

The Python script is a **reconstructed** reproduction script, not the original analysis code. It requires the authors' private workbook and therefore cannot independently regenerate the aggregates using only the public files. The published CSV and verification report are directly inspectable.

## Citation and status

This repository is a limited supporting-data release, not a complete reproducibility package for the manuscript. A GitHub URL is not a DOI. When citing a frozen version, use a GitHub release or a commit permalink.
