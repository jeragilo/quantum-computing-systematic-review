# Data dictionary

`data/domain_year_counts.csv` contains aggregate counts of **Scopus search occurrences**, not unique papers. A publication may appear in multiple QC domains.

Columns (as exported):
- `domain`: domain identifier (QC01–QC08)
- `publication_year`: publication year
- `record_occurrences`: number of search occurrences

The 2026 observations are incomplete-year data; domains use different publication windows.
